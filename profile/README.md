### NAIRR Workshop Series: Cybersecurity, Edge AI & Autonomous Systems

A NAIRR EAGER project with **Worcester Polytechnic Institute**: 13 sessions across three tracks and four case
studies, all runnable in a browser on the NAIRR Pilot through Jetstream2.

| Track | Workshops |
|---|---|
| 🛡️ Cybersecurity | 2.1 AI for Cybersecurity · 2.2 Security of AI Development |
| ⚡ Edge AI | 3.1 Efficient Inference · 3.2 Domain-Specific Optimization |
| 🚗 Autonomous systems | 4.1 AI for Autonomous Driving · 4.2 Sensing & Controlling · 4.3 Sensor Fusion |
| 🧩 Case studies | 5.1 · 5.2 · 5.3 · 5.4 |

**[Browse all workshops →](https://ou-care-ai.github.io/nairr-eager/#workshops)**

### Using our compute

Research groups we partner with can run work on the project's Jetstream2 allocation.

- **Today:** read the [researcher guide](https://github.com/OU-CARE-AI/researcher-guide) — what else runs on the allocation, what things cost, and the rules.
- **Coming:** request an instance by [opening a GitHub issue](https://github.com/OU-CARE-AI/vm-requests), with automatic idle shutdown.
